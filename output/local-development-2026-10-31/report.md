## 浏览器实测

| 页面与操作 | 观察结果 |
| --- | --- |
| 邀请链接 → 邮箱验证码 → 称呼／密码 → 注册 | 邮箱验证后才出现设置密码，注册后回正常登录，加入正确家庭 |
| 登录 → 添加傍晚活动 → 保存 | 页面显示持久化的安排；其他餐次保留 |
| 独立日常成员登录，375×812 | 读取同一份计划，可调整活动；没有关键宝宝资料和成员管理写入口 |
| 两成员同时编辑同一事项 | 一次成功、一次冲突；输入保留，展示家人最新内容，明确核对后才能继续保存 |
| 日常成员断网后保存 → 恢复网络重试 | 显示连接失败、保留输入；重试后保存并同步到另一账号 |
| 新日期新增，服务器保存后阻断响应，再次保存 | 仅有一项安排；刷新页面后仍可读回，没有重复创建 |
| 管理员移除成员 | 对方同步连接被终止，客户端清除原家庭安排，接口拒绝旧访问 |
| 邀请成员退出 → 请求重置 → 打开完整邮件链接 → 新密码 | 重置后不会自动登录；使用新密码可正常进入家庭 |
| 新管理员创建家庭、刷新后继续宝宝初始化 | 保存进度与完整界面回归；详见本轮初始化截图 |
| 1440px 桌面、375px 手机、1280px 平板大字 | 已检查截图；手机与平板无横向溢出，大字模式保留编辑入口 |
| 家庭页 1440／1024／820／375px | 修复长设备信息挤压栅格；电脑两栏等宽，小屏单列；四种宽度均无横向溢出 |
