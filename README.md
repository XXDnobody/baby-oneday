## 本机运行

首次运行执行 npm run env:up:test、npm run local:setup、npm run dev；另开终端运行 npm run worker 处理持久化任务。已有环境升级只需 npm run db:migrate。应用入口为 http://127.0.0.1:3000；一次性首位账号注册链接保存在被忽略的 .local/first-registration-link.txt。本地验证码和重置邮件在 http://127.0.0.1:8025 查看。local:setup 可重复执行，不会重置账号或建立第二份初始化资格。

npm test 会重建独立测试库的业务表，禁止连接开发库；npm run dev:test 在 3001 端口启动测试应用，使用独立构建目录。npm run check 执行类型检查、lint、接口测试和构建。npm run db:verify-backup 将测试库恢复到临时独立数据库，核对后移除恢复副本；备份只保存于被忽略的 .local/backups。npm run trash:purge 显式清理已删除且超过 30 天的正文，测试环境须加 -- --test；不会按年龄清理仍有效的旧记录。

外部服务默认关闭。npm run env:services 只列出配置缺项，示例在 .env.example；不要把密钥放进聊天或 NEXT_PUBLIC_*。npm run dev:test:b3 使用 3001／5433 和明确标记的测试天气／模型，必须在接口测试完成后联调；不能据此认定真实服务通过。

完整命令与环境边界见[本地开发与测试方案](docs/本地开发与测试方案.md)及[B3 本地实现](docs/B3本地实现说明.md)。

## 已确定的产品方向

- 先让自家持续使用，再邀请 10～20 个家庭进行 7 天试用，随后测试家庭会员收费；初期只设一种付费会员，采用激活码交付。
- 一个家庭购买、家人分别登录并共享权益；试用资格、会员开通与加入家庭分别处理。到期后保留已有内容的查看与导出，记录保存期限提前明确。
- 对外分享使用示例或预览后的去身份信息快照，引导新用户创建自己的家庭；家庭内部邀请仅供照护者加入。
- 你为家庭管理员，宝宝妈妈和奶奶均可编辑日常安排；奶奶可以直接换餐、调整活动与时间。记录更正或删除仅限记录本人和家庭管理员。
- 沿用工作日、周末的生活节奏，根据现有食材、天气、活动场景和近期偏好安排内容。
- 日常安排在已认可的内容和规则范围内自动展示，修改一餐或一项活动时保留其他安排。
- 平板直接登录家庭成员账号，在平板上查看、记录和操作；平板模式保留大字计划、下一项安排和共同提醒，权限跟随成员。
- 食材在排餐前简单确认，活动反馈可选，菜谱与当天安排可打印。
- 饮食、活动和穿搭保留具体出处与改编说明，推荐理由对应实际家庭记录或活动时段天气；家庭认可、出处核对和专业审核分别标注。
- AI 通过统一入口讨论今天或本周安排；聊天和未确认方案仅本人可见，涉及正式业务的改动先预览、一次确认后保存并共享。
- 每天晚上准备次日安排，一周计划按需生成；人工修改受保护。邮箱＋密码登录，常用设备保持登录；忘记密码时邮件重置。
- 妈妈、奶奶可改食材、近期偏好和作息模板；宝宝关键资料、禁忌及自动生成设置由管理员修改。
- 家庭照片上传与留存已取消，记录保留文字、参与情况和兴趣反馈；活动卡说明配图保留。
- 自家计划和文字记录使用期间保留，删除后 30 天内可恢复；回收站沿用当前成员权限，历史计划和实际记录分别处理。
- 统一日历覆盖未来计划、当天记录和历史回顾；关键节点可留感想、参与情况与兴趣反馈，同一活动多次开展分别保存。
