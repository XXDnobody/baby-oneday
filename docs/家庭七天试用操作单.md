# 家庭七天试用操作单

准备日期：2026-10-31（Asia/Shanghai）。**本页是待执行的操作单，没有记录七天使用完成。** 计划窗口仍为 2026-11-14（周六）至 11-20（周五）；只有准入条件齐备后才确定实际第一天。延期后重新选择连续七个自然日，覆盖工作日和周末。

上述条件未满足时可以做本机演示及准备，**不登记为完整 S1 家庭试用的第一天**。真实服务、真机、纸张和连续使用都须另留实际证据。

## 每天的固定步骤

1. 早上分别用本人账号打开，确认宝宝、日期、家庭、最后同步时间及当前网络状态；核对天气地点、活动时段、来源、取数时间和是否过时。
2. 核对当天食材和需要采购／确认的原用量，查看一条菜谱或活动的步骤与来源。无适用内容时保留“待安排”，不把未知资料当作适用结论。
3. 由一位家人调整一项安排，另一位在手机／平板查看同一版本；核对其他时段没有被改写。记录保存成功或失败的实际提示。
4. 正常使用后可写一条文字、参与或兴趣反馈；没有记录保持未知，不因时间经过认定完成。避免为了测试补造宝宝表现。
5. 晚上查看次日准备结果，确认人工安排、主动留空和已删除时段没有被补回；记录问题及当日结果。没有实际启用夜间任务时，不声称自动准备已通过。

## 家庭需集中补齐的资料

- 实际使用人、手机和平板型号／浏览器、打印机与纸张条件，以及可使用的受控访问地址。
- 现有宝宝资料是否准确，生日或月龄依据、当前食物限制及确认人；未知项保留未知。
- 工作日／周末真实作息、场景、照护分工和共同提醒；首批真正能用的内容版本及缺项核对结果。
- 天气实际地点与坐标出处；已有天气和 AI 账号的配置、模型／地域、额度及费用限制。密钥只填本项目受忽略的环境文件，不发聊天。
- 实际邮箱投递条件、服务器容量与有效期、备份位置和周期、可接受数据丢失窗口与恢复耗时，以及准入通过后的实际七天日期。
