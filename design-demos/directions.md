# 六个候选与三个完整方向

三版都遵从用户「偏简洁、清楚的工具界面」；来源仅作为设计方法参考，不暗示合作或背书。

## A 日常工作台｜完整方向 dir-1.html

最佳设计师思路：深泽直人的日常顺手与低干扰（官方站已核实，维护中，未假装看到其网页作品）。借的是把高频行为放在稳定位置这一方法判断。窄侧栏 + 宽主区 + 右侧当天计划，主区上方当前/下一项，下方活动与餐食天气。近白背景、深松绿操作色、极浅鼠尾草状态面，中文无衬线。主角是含照护者的时间线；唯一强调处是当前/下一项并列。Form 来自多人照护的接力与局部改动。参考 https://naotofukasawa.com/ 。

## B 陪伴清单｜完整方向 dir-2.html

最佳设计师思路：Koto 的友好与明确识别，收敛为清楚的工具界面。水平导航、横向当日时段带、左侧宽活动说明 + 右侧餐食/天气 + 下方家庭约定。白底、蓝灰字、浅杏色和少量琥珀色；图像只占活动区约1/3，按钮用深蓝。主角素材是积木与收纳篮的生成示意图，展示室内备选所需材料。最大差异是把「怎么陪玩」作为宽内容区，不把陪玩埋在附属卡片里。Form 来自父母需要当场知道怎么玩。参考 https://koto.com/ ，不复制品牌资产。

## C 一眼看清｜完整方向 dir-3.html

秒数轮盘：采样秒数 S=26，网页20种得到第7「复古未来太空图录」。参考样张 `web/07-cosmic-retro-futurism.jpg` 已亲眼查看。保留白/深墨/钴蓝、左右强对比、字号悬殊与细刻度；去掉天体轨道和无关宇宙隐喻，约70%的视觉特征迁移。主骨架：顶导航 + 左侧深蓝当前/下一项大区 + 右侧宽清单，底部横向一天安排。中文无衬线以保证工具可读性，数字可用 Georgia 拉开层级。主角是大字号下一项时间和照护角色。Form 来自家人走过平板时的远读需要；管理页仍能在清单上直接操作。

## D 时间排程｜备选

现实参照 Sunsama 官网中的真实产品界面（已截图 `refs/web-reference-board-1.jpg`）。借三列「导航/任务/时间轴」、紧凑行距与轻分隔，白灰+低饱和橙，主角全天时间刻度。Form 来自父母一次查看整天安排。与A同属高效率工具界面，差异不够大，因此留备选。https://www.sunsama.com

## E 家庭协作板｜备选

现实参照 Milanote 官网中的 Web 画板界面（已截图 `refs/web-reference-board-2.jpg`）。借分区可见性、不同内容按列组织、图文块大小层次；不使用无限画布或倾斜便笺。主角是「照护/做饭/陪玩」三列任务，淡蓝背景、白色内容、深墨标题。Form 来自家庭成员接手不同任务。比A多一步找时间，留备选。https://milanote.com/inspiration/create

## F 家庭手册｜备选

秒数轮盘：S=26，东亚12种得到第3「民国书衣」。样张 `east/03-republic-book-jacket.jpg` 已亲眼查看。借窄题签与分栏阅读、低饱和浅纸色/墨绿，取消双线花框和大竖排，避免妨碍工具检索；作为原风格的简化迁移，视觉还原不足70%，明确降低纸张拟物与竖排。主角长条菜单与活动步骤，适合菜谱打印和说明阅读。Form 来自奶奶需要清楚做法，但管理效率较弱，留备选。

## 选择原则

先将六个候选画在 `thumbs.html` 并亲眼检查，再展开A/B/C。三张完整方向有不同骨架：侧栏工作台、水平清单、分屏看板；未选方向待用户选择，不提前定稿。
