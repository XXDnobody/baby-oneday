# 宝宝计划 Web UI 设计初稿

> 历史目录说明（2026-10-29 补充）：本目录保留 2026-10-28 选定方向前的三份初稿及当时记录。用户随后已选择 A，当前原型见[交付说明](../web-ui/README.md)，现行规则见[产品需求](../docs/产品需求.md)。下文和本目录中的“尚未选择”“只读大屏”等仅描述历史阶段，不能作为当前开发依据。

依据已确认的需求范围，遵从本轮偏好 **「偏简洁、清楚的工具界面」**。

## 打开方式

打开 `index.html` 可切换三个方向、桌面/手机预览以及并排比较。三个方向也可单独打开：

| 文件 | 方向 | 核心组织方式 |
| --- | --- | --- |
| `dir-1.html` | A 日常工作台 | 侧栏、当前事项、全天时间线 |
| `dir-2.html` | B 陪伴清单 | 水平时段带、宽活动说明、餐食天气 |
| `dir-3.html` | C 一眼看清 | 深浅分屏、大字下一项、清楚的准备清单 |

独立方向文件内嵌样式、脚本和所需图像；比较页与截图共同保留在本目录。

## 可评审内容

- 示例工作日今日页及手机布局。
- 晚餐从面换饭、确认已有食材、切换室内活动、展开玩法与可选反馈。
- 家庭大屏只读预览、菜谱与当日安排打印快照。
- 日期、天气示例、来源待核对、本地保存等状态表达。

## 文件说明

- `spec.md`：三版共同需求、示例数据、范围与设计假设。
- `directions.md`：六张方向卡、参考来源与筛选理由。
- `thumbs.html`：六个真实候选缩略稿。
- `screenshots/`：浏览器渲染的首屏、完整页、手机与交互截图。
- `refs/`：已实际截取和查看的网页参考板。
- `assets/`：积木收纳示意图与生成提示词记录。
- `product-facts.md`、`brand-spec.md`：事实与品牌边界。
- `verification.md`：交付前验证结果。

## 阶段与限制

这是方向选择阶段的高保真设计原型，未接入真实账号、天气、AI、云端数据或家庭设备同步。时间、菜单和天气均是固定演示场景；未给出的作息时间是示例配置。活动内容尚待逐条核对与家庭启用，图像为材料示意。

本地交互用于评审流程，不能据此确认后端并发修改保护、离线缓存、数据隔离或大屏设备权限已经实现。平板远读效果、打印机分页和真实食谱适用性仍需实际验证。

在三方向初稿交付时，依照当时调用的 huashu-design 技能先展示三个方向，尚未取得选择原话。后续已选定 A 并扩展页面，确认记录见[方向确认](../web-ui/direction-approved.md)；本目录继续保留初稿，不改写为后续版本。
