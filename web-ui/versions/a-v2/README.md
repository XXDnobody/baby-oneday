# 宝宝计划 · A 日常工作台

依据用户“我选择A”，沿用已确认的A版布局和松绿配色，扩展为可点击的完整核心页面。形式来自家庭照护交接：把“现在、下一项、怎么做”放在最先看到的位置。

**本轮扩展（2026-10-28）：** 新增AI助手、统一日历、记一下和记录详情。已串起讨论→改动预览→一次确认、过去记录回看、临时事件补记、按次留存和照片失败重试。入口为 [新增页面总览](extension-overview.html) 与 [新版交互评审](review.html?page=calendar)。

原8个核心页面继续可用；上一版核心文件保留在 `versions/a-v1/`。

## 查看方式

- **设计总览**：[overview.html](overview.html)，查看原有核心页面；新增4类页面见 [本轮总览](extension-overview.html)。
- **交互评审**：[review.html](review.html)，切换电脑、手机、平板、标准/大字与异常状态。
- **独立原型**：[index.html](index.html)，也可以直接用浏览器打开；需保留同目录的 CSS、JS 文件。
- **规范**：[design-spec.md](design-spec.md)。原始三个方案保留在 `../design-demos/`。

如果需要在同一浏览器的不同标签页演示联动，可以从项目根目录启动本机HTTP服务，再打开 `/web-ui/review.html`。

## 页面与交互

| 入口 | 内容与可体验操作 |
| --- | --- |
| `#today` | 当前/下一项、时间线、天气与穿搭、换餐、切换室内外、大屏与打印 |
| `#meals` | 今日餐次、单餐替换、近期偏好、采购核对、调整单项时间 |
| `#pantry` | 现有食材、粗略余量、优先吃、确认时间、字段校验 |
| `#activities` | 快速玩法、展开目的/观察/调整/来源、室内备选、这一次活动的记一下 |
| `#recipe/noodles` | 原料与步骤、大字字号、单道菜谱打印 |
| `#family` | 分工与资料、工作日/周末预览、共同提醒、设备配对流程示意 |
| `#display` | 只读摘要、共同提醒、只读大字菜谱 |
| `#assistant` | 明确范围、继续讨论、改动对照、最终版本确认与保存结果 |
| `#calendar` | 月/周选日、正式计划、实际记录、过去回看与未来安排 |
| `#record/new` | 发生日期、可选参与/反应/感想/照片、独立补记 |
| `#record/demo-blocks` | 示例记录详情、当时安排、更正、单条删除、再记一次 |
| `#print` | 选择内容、生成固定快照、重新生成、浏览器打印 |

评审选项提供未安排、天气未更新、离线、推荐不可用、保存冲突、AI保存失败、照片保存失败和大屏授权撤销的状态示例。保存冲突选项会在第一次保存时模拟另一位家人的新改动。它们用于验证界面，不表示接入了这些外部服务。

## 内容与数据

17个月与家庭分工来自需求。日期2026-10-28、14:40演示时刻、天气和部分计划内容是示例。早餐、午餐的具体菜谱保持待补充。菜谱份量、禁忌与内容核对状态均明确可见。

修改保存在本机浏览器，同源标签页可演示联动。服务端账号、家庭隔离、设备权限、真实天气、AI和跨设备同步尚未接入。产品中的只读展示与冲突界面不能替代后端权限与并发控制。

登录和邀请方式尚未定案，本轮不擅自指定认证渠道。日常模板先提供预览和单日调整，完整模板编辑与初次设置留待产品实现阶段细化。
