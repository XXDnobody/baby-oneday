# 宝宝计划 · A 日常工作台

依据用户“我选择A”，沿用已确认的A版布局和松绿配色，扩展为可点击的完整核心页面。形式来自家庭照护交接：把“现在、下一项、怎么做”放在最先看到的位置。

**本轮扩展（2026-10-28）：** 新增AI助手、统一日历、记一下和记录详情。已串起讨论→改动预览→一次确认、过去记录回看、临时事件补记、按次留存和照片失败重试。入口为 [新增页面总览](extension-overview.html) 与 [新版交互评审](review.html?page=calendar)。

原8个核心页面继续可用；此前核心文件保留在 `versions/a-v1/`，平板修订前的扩展版保留在 `versions/a-v2/`。

**需求口径更新（2026-10-29）：** [产品需求 v0.10](../docs/产品需求.md)和[开发规格 v0.5](../docs/开发规格.md)已统一邮箱＋密码、首次验证邮箱、邮件重置、保持登录、奶奶日常编辑、私有 AI 聊天、每晚准备次日及记录作者／管理员修改权限；家庭照片功能已取消，内容启用范围仅管理员管理，活动卡以图文为主。本次只对齐文档；原型中的照片入口、上传重试和照片限制保留为历史演示，后续实现须移除，不能作为当前需求或验收依据。原型的权限与登录演示不代表真实业务实现。文档分工与待定项见[需求对齐与待定事项](../docs/需求对齐与待定事项.md)。

妈妈、奶奶可以修改食材、近期偏好和作息模板，宝宝关键资料、禁忌及自动生成设置由管理员修改。正式文字反馈记录按家庭读取权限查看；修改或删除记录仅限作者或管理员。微信留待后续；原型仍保留演示流程，邮箱注册、验证与重置、初始化、邀请、来源详情和最新权限呈现待补齐。

**需求补充（2026-10-30）：** 产品需求已整理为 v1.0 的 S1 评审稿；自家计划和文字记录使用期间保留，删除后 30 天内可恢复。回收站、恢复预览与到期处理是新增待实现流程，本次未修改运行页面或重跑原型测试；现有演示不能证明删除恢复、真实权限或备份已经实现。

## 页面与交互

| 入口 | 内容与可体验操作 |
| --- | --- |
| `#today` | 当前/下一项、时间线、天气与穿搭、换餐、切换室内外、平板模式与打印 |
| `#meals` | 今日餐次、单餐替换、近期偏好、采购核对、调整单项时间 |
| `#pantry` | 现有食材、粗略余量、优先吃、确认时间、字段校验 |
| `#activities` | 快速玩法、展开目的/观察/调整/来源、室内备选、这一次活动的记一下 |
| `#recipe/noodles` | 原料与步骤、大字字号、单道菜谱打印 |
| `#family` | 分工与资料、工作日/周末预览、共同提醒、平板登录说明 |
| `#display` | 平板主页：大字摘要、菜谱、日历、记录、换餐与时间调整 |
| `#assistant` | 明确范围、继续讨论、改动对照、最终版本确认与保存结果 |
| `#calendar` | 月/周选日、正式计划、实际记录、过去回看与未来安排 |
| `#record/new` | 发生日期、可选参与/反应/感想/照片、独立补记 |
| `#record/demo-blocks` | 示例记录详情、当时安排、更正、单条删除、再记一次 |
| `#print` | 选择内容、生成固定快照、重新生成、浏览器打印 |

评审选项提供未安排、天气未更新、离线、推荐不可用、保存冲突、AI保存失败、照片保存失败和登录过期的状态示例。保存冲突选项会在第一次保存时模拟另一位家人的新改动。它们用于验证界面，不表示接入了这些外部服务。

## 内容与数据

17个月与家庭分工来自2026-10-28需求访谈，正式系统使用家庭填写的月龄依据。日期2026-10-28、14:40演示时刻、天气和部分计划内容是示例。早餐、午餐的具体菜谱保持待补充。菜谱份量、禁忌与内容核对状态均明确可见。

修改保存在本机浏览器，同源标签页可演示联动。服务端账号、家庭隔离、成员权限、真实天气、AI和跨设备同步尚未接入。权限说明与冲突界面不能替代后端权限与并发控制。

平板使用与手机、电脑相同的成员登录，不需要设备配对；正式登录已确定邮箱＋密码、保持登录及邮件重置，当前仍为演示流程。家庭成员邀请采用与试用码、会员激活码分开的链接，具体有效时长和服务仍待实现。日常模板先提供预览和单日调整，完整模板编辑与初次设置留待产品实现阶段细化。

2026-10-28 已确认[分享与家庭会员方案](../docs/分享与家庭会员方案.md)：按家庭购买、家人共享权益，先邀请 10～20 个家庭进行 7 天试用，再测试一种付费会员。当前仅同步需求和页面规划，原型未增加试用、购买、激活、到期导出或公开分享功能，29 元／家庭／30 天仍为待验证测试报价。
