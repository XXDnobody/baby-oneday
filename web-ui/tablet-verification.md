# 平板直接操作修订与验证

> 版本说明（2026-10-29 补充）：本报告保留 2026-10-28 平板原型的验证证据。验证时认证渠道未定；随后已确定邮箱＋密码、首次验证、保持登录和邮件重置，见[开发规格](../docs/开发规格.md)。这次补注不表示真实登录或新版权限已实现，也未重跑测试。

日期：2026-10-28（Asia/Shanghai）。沿用已选定的 A「日常工作台」。

用户原话：“这个大屏其实我觉得正常也就是用平板进行登录，所以应该就是平板上操作就行”。

## 修订结果

- 原“家庭大屏”改为“平板模式”，作为同一系统的大字触屏布局。
- 手机、电脑和平板共用成员登录；验证当时具体认证渠道尚待确定。权限跟随成员，不建立只读设备身份，也不需要手机配对。
- 平板主页可直接打开菜谱、日历、食材、活动、AI助手和记录，支持换餐与调整时间的本机演示。
- 大字菜谱保留食材核对和打印入口；从日历、记录和其他页面可以返回平板主页，也可切回普通视图。
- 登录过期时，各路由显示本机登录入口；“使用演示账号继续”明确属于原型演示。

形式来自家人坐在平板前的实际操作：大字摘要方便抬眼查看，常用操作放在同一屏幕，按钮便于触摸。

## 已验证

使用现有 Playwright 浏览器环境，检查了以下行为并目视核对最终截图：

| 检查 | 结果 |
| --- | --- |
| 在平板直接换晚餐 | 保存成功，只改选定餐次，其他餐次、日程和食材保留 |
| 调整当前计划的时间 | 在本机完成，无需进入手机端 |
| 打开大字菜谱并核对食材 | 入口可用，可返回平板主页 |
| 记录文字和照片 | 关联本次活动保存，并从日历找回 |
| AI与普通视图切换 | 本机入口可用，切换布局保留家庭数据 |
| 登录过期 | 主页、菜谱、日历、记录、家庭和AI路由均不继续显示家庭内容；本机演示登录后恢复 |
| 横竖屏 | 1440、1280、1024、820、768、375六种宽度，标准及大字均无横向溢出 |
| 触屏区域 | 主页常用按钮至少44×48像素 |
| 电脑和手机回归 | 今日、饮食、家庭、日历、记录及菜谱页面无横向溢出 |
| 评审入口 | 默认平板尺寸，正常与登录过期状态可切换 |
| 浏览器与设计检查 | 无脚本错误；设计检查无红灯或模板装饰提示 |
