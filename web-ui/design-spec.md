## 设计系统

直接继承A的实际值：主色 `#214F42`，深主色 `#183E33`，文字 `#24362F`，次要文字 `#65726B`，背景 `#F6F8F5`，浅绿 `#EDF3ED`，选中浅绿 `#E2EBE1`，边框 `#E1E7E0`，白 `#FFFFFF`，提醒背景 `#F7F2E6`，提醒字 `#76612F`。桌面侧栏188px，主区间距28/32px，面板圆角18px、按钮9px，点击区至少44px。

## 页面与形式

| 页面 | 内容角色与阅读距离 | 容量与形态来源 |
| --- | --- | --- |
| 今天 | 电脑50–80cm快速了解接下来做什么 | 延续A当前/下一项、活动、晚餐天气、右侧时间线，来自照护交接 |
| 饮食 | 父母查看与局部调整 | 左侧餐次清单、右侧优先食材与采购核对，来自备餐顺序 |
| 家里食材 | 排餐前短操作 | 食材行、粗略余量、优先吃、已确认时间，来自家庭快速盘点 |
| 活动 | 准备陪玩时近读 | 当前活动、步骤、室内备选；展开目的/观察/调整/来源，来自边看边做 |
| 菜谱 | 奶奶近读或大字阅读 | 原料与清晰编号步骤，来自实际做饭过程 |
| 家庭 | 设置与交接 | 成员、模板、共同提醒、平板入口与登录说明，不展示无意义的成长统计 |
| 平板模式 | 平板触屏操作，兼顾大字阅读 | 当前与下一项、菜谱、穿搭、玩法与约定，直接记录、换餐、调整时间和打开日历 |
| 打印 | A4近读 | 当日安排与选中菜谱的固定快照，带日期/更新时间 |

共用顶部标题、侧栏导航、面板、按钮、抽屉、提示条；不同页面通过容量和任务改变内容排列。当前原型采用手机五个底部导航：今天、日历、饮食、活动、家庭；详情可返回所属页面。

## 流程与状态

1. 饮食 → 确认食材/余量/优先吃 → 替换晚餐 → 确认影响范围 → 更新当前安排与采购核对。
2. 活动 → 查看快速玩法及依据 → 切到室内备选 → 可选反馈，初始仍为未知。
3. 平板直接登录 → 打开平板模式 → 看大字菜谱、核对食材、查日历、记录，按成员权限换餐或调整安排 → 返回平板主页。
4. 打印 → 选择当日安排/菜谱 → 生成快照 → 本地内容再改动时，快照内容保持固定，显式重新生成才更新。
5. 时间调整只改选定安排，时间线按固定演示时刻14:40定位，不记成完成。

评审入口提供标准/大字两种字级、电脑/手机/平板视口，以及离线、天气未更新、并发修改等状态示例。评审控制留在产品界面之外。

## 内容与实现边界

日期2026-10-28、宝宝17个月、家庭角色沿用需求；天气、未给出的时刻、餐次仍是示例。活动来源保留已核实的 UNICEF 页面入口与「待逐条核对」状态。菜谱是家庭自定义内容示例，份量待填写，不能冒充专业审核内容。

本机浏览器保存演示状态；同源标签页可以通过 storage 事件展示更新，准确称为本机演示联动。真实账号、服务器同步和成员权限校验不在UI交付中；平板模式仅改变布局，正式读写权限按成员校验。

手机、电脑和平板共用成员登录。首版已确定邮箱＋密码、首次验证邮箱、保持登录与邮件重置；家人通过独立家庭邀请链接加入，邀请有效时长仍待落实。登录过期在本机重新登录，原型目前只提供演示流程。

## 新增需求的本轮原型范围（已完成页面与交互演示）

用户已确认 AI 先展示改动清单、一次确认后统一保存，以及计划和回顾使用同一日历。沿用 A 的视觉系统和工作台布局，增加以下内容；详细交互以最新 [页面结构](../docs/页面结构.md) 为准。

| 范围 | 本轮呈现的内容 |
| --- | --- |
| AI 总入口 | 管理页顶栏固定入口、今日页对话入口；电脑侧面板和手机完整对话页 |
| 方案确认 | 明确日期范围、按日浏览方案、改动前后对比、继续讨论、最终版本确认与保存结果 |
| 导航与日历 | 建议手机增加为“今天、日历、饮食、活动、家庭”；电脑侧栏增加日历；月历与选中日时间线 |
| 记录与照片 | 活动卡“记一下”、可选参与情况和文字照片、独立记录临时事件、补记与详情 |
| 历史回顾 | 同一活动每次分别保存；回看当时计划、家长原话、照片和记录人 |
| 例外状态 | 方案过期或冲突、保存失败、暂无记录、照片上传失败与重试 |

新增原型中的 AI 回复、照片和上传状态必须明确属于演示，不得作为已接入真实服务的证明。本轮记录已按发生日期和活动次数独立关联，原按活动类型的反馈区域已替换为“记一下”。旧反馈不推断为真实活动记录。详细设计见 [extension-spec.md](extension-spec.md)，新增验证见 [extension-verification.md](extension-verification.md)。

## 平板直接操作（本轮修订）

依据用户“这个大屏其实我觉得正常也就是用平板进行登录，所以应该就是平板上操作就行”。沿用A方向，原“家庭大屏”改名为“平板模式”；以触屏操作为主，摘要和大字保留便于抬眼查看。顶部提供日历、饮食、食材、活动、AI与记一下；当前计划可调时间，下一餐和晚餐可换餐，活动可直接记录。本机保存视图偏好，普通页面提供返回平板主页；普通视图切换不改变数据和成员权限。

平板菜谱使用大字，但允许继续核对食材和打印。登录过期示例覆盖各路由，在平板本机恢复；真实登录与服务端权限尚未实现。验证见 [tablet-verification.md](tablet-verification.md)。
